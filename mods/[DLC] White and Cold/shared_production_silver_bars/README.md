# Shared Production Silver Bars

Shared production of silver bars in the New World based on the scenario production to use as sub-mod.

## Do not modify contents of this mod

Making changes may break mods and cause compatibility issues.

## How to Use

Copy the `shared_production_silver_bars` folder into your mod folder and add `shared_production_silver_bars` to your `LoadAfterIds`.

### Menu Unlock Guide

- Always add your own unlock condition for the silver asset pool (`1742200048`) to unhide and unlock the production for your own mod.
- There is a production chain (`1742200041`) already available for the New World. Add the production chain to the location of your liking in the New World construction menu. Use a condition to check if the chain is already added by another mod to make sure it is not added multiple times.
- This submod includes the submods for all the different goods used in this mod.
